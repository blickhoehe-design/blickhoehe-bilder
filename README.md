# BLICKHÖHE — Bilder

Öffentlicher Ablageort für die Beitragsgrafiken von @blickhoehe.

Instagram holt Bilder beim Veröffentlichen selbst von einer öffentlichen
HTTPS-Adresse ab. Dieses Repository ist diese Adresse.

Gerendert wird in `../render/` mit Remotion. Dieser Ordner enthält nur die
fertigen PNGs, kein Quellmaterial und keine Konzeptunterlagen.

## Adressformat

    https://raw.githubusercontent.com/<konto>/blickhoehe-bilder/main/beitrag-01.jpg
